# 17号住宅：空间与环境动画重制

本次针对原先一楼试摆、二楼仅走廊注册、卫浴与屋顶占位的问题，完成八个房间的绘制。所有美术仍由 Canvas 2D 代码绘制，不增加运行时依赖或外部图片。

## 检视

启动原游戏后，在开始菜单选择「探索17号住宅」。另可打开 `house-preview.html`：切换八个空间、移动镜头、暂停/拖动时间、切换门窗，并显示 120px 人形尺度标尺。标尺不是正式角色；预览页不加载公路调色和全局灯光合成，不能代替完整游戏验收。

## 改动

- 保留 330px 原生画高、240px 地板起点和 246–312px 行走带，以约 120px 成人高度统一家具：门高 142px、餐桌高 52px、台面高 63px、冰箱高 131px。家具地面接触线明确，增加顶部亮面、侧面和接触阴影。
- 一楼从玄关、客厅、楼梯到餐厨清晰分区。厨房补冰箱/排班表、炉灶、水槽、吊柜；餐桌餐具、急救包、留言与原线索位置对应。挡门椅随维修间门状态移开。
- 二楼补主卧、儿童房；补齐卫生间、家庭浴室、洗衣维修间、门廊屋顶。窗户、门和梯子与原交互点对应。
- 实时窗帘、钟摆、吊灯轻摆、植物、滴水/波纹、纸鸟、晾晒织物、云和落叶。灯源接入原 `sceneLighting`，采用缓慢电池光变化，不做高频闪烁。
- 静态建筑与家具按房间缓存，只有环境动效实时绘制。动画由传入时间驱动，纹理固定种子；重新注册只使对应房间缓存失效。
- 支持系统 `prefers-reduced-motion`：环境动画与光源变化冻结，但门窗交互仍有效。绘制方法恢复 Canvas 状态，窗外景物和云层采用裁剪，不泄漏到墙面。

## 保持不变的内容

`house-data.js`、`game.js`、`index.html`、角色、战斗和外部场景未改。所有房间长度、门/楼梯/窗/梯子的目标、线索、补给和居民位置保持原值。上楼近段仍为 `(400,292) → (490,232)`，未调整游戏的穿门/爬梯转场。

本次是环境绘制重制，**没有新增家具实体碰撞系统**，也没有改动敌人寻路或存档语义。

## 验证

零额外依赖的住宅测试：

```sh
node --test tests/house-render.test.cjs
```

覆盖八个房间注册与缓存、有限几何、Canvas 状态恢复、确定性动画、减少动态效果、门状态、灯源和原始门户/线索数据。

可选真实浏览器截图与像素回归（需要 Python Playwright 和 Chromium）：

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/house-visual.py
# 使用现有浏览器：CHROME_BIN=/path/to/chromium python3 tests/house-visual.py
```

脚本离线内联同一份源代码，无需本地服务器，输出到 `output/house-refresh/`。检查同一时间像素一致、不同时间画面变化、减少动态效果、门切换、390px 手机布局和页面异常。

提交前运行结果：住宅 Node 测试 7/7 通过；八房间真实 Chromium 检查通过、页面异常为 0、390px 无横向溢出。五个修改的 JS 文件通过 `node --check`。

**验证边界**：本次没有在完整项目环境运行原 `npm test`，也没有完成正式角色、战斗、全局调色/灯光的浏览器端到端验收。合并前请运行原 `npm run check && npm test`，并从开始菜单实际走一遍楼梯、儿童房窗口、屋顶梯子和维修间。
