# LAST LIGHT · 死线突围

以荒野公路为背景的原创像素生存射击游戏。无构建依赖，Canvas 2D 实时绘制像素场景和角色。

## 运行

```sh
npm start
```

打开 http://127.0.0.1:5173，也可以直接打开 `index.html`。

## 操作

- WASD / 方向键：移动
- 鼠标：瞄准；步枪、冲锋枪与霰弹枪按住左键连续射击；手枪每次点按左键发射一发；撬棍左键挥击，每次消耗 16 体力
- 1–5：切换 AK-47 步枪、MP5 冲锋枪、M870 霰弹枪、M1911 手枪、撬棍；Q：轮换武器
- M1911 初始弹药为 10 / 90；撬棍以体力驱动，无需弹药
- R：仅为枪械换弹，空弹匣会自动换弹；切换武器取消当前装弹，各枪械独立保存弹药
- Shift：冲刺，消耗体力
- Esc / 空格：暂停或继续
- Enter：开始 / 重新开始
- 触屏：屏幕方向键、换弹和开火按钮；开火时瞄准最近的僵尸

普通丧尸的基础速度已提升至原来的 2 倍，并强化追击压迫、特殊攻击与受击表现。断肢独立细分为上臂（arm）、前臂（forearm）、大腿（leg）与小腿（shin）；命中对应部位会留下像素血肉断面和断肢。失去一条小腿后跛行，失去任意大腿或双小腿后爬行。腿部损伤与任意臂段缺失同时出现时，丧尸停止自主移动与特殊冲锋；双腿缺失但双臂完整时，仍能依靠手臂爬行。断臂也会削弱攻击。头部伤害依武器和丧尸类型计算，重装丧尸能承受更多命中。每五次击杀掉落弹药或医疗补给，走近即可拾取。每波结束恢复部分生命并补充弹药；后续尸潮逐渐增强。最高击杀记录保存在当前浏览器。

横向卷轴地图长 6400 像素，从暮色农场经过废弃加油站、隔离边界至铁锈工业区。区域边界提供补给，抵达东端后清空残余尸群即可撤离。远山、云层和电线随镜头分层移动，烟、旗帜、草、鸟群和警示灯持续变化；道路采用平行侧视透视，静态背景按块缓存。场景整体压低明度与饱和度，为角色和血肉反馈让出对比。

特殊丧尸包括短暂蓄力后扑击的疾行者、耐伤冲撞的重装暴君、向预判位置抛射腐液并留下危险地面的喷吐者。

所有游戏美术均由代码绘制，无需下载素材。字体加载失败时使用系统字体。开始游戏后启用声音，右上角可关闭。

## 美术风格

以《They Are Coming!》一类横版尸潮射击为参照：角色厚重易读、打击反馈夸张，冷色丧尸站在暖色世界前。

- 场景是舞台而非主角：农田、芦苇、路肩等中景色带降低约四成饱和度与一成半明度，公路改为偏冷的灰蓝底色，碎石纹理减少到原来的三分之一并压在底色 ±3 明度内，只保留车道线为高饱和暖黄。
- 地平线遵循大气透视：电线、电杆、树带和远处城市轮廓统一向天空色靠拢，不再以深色剪影切割画面。
- 路边建筑、车辆、路障和路牌的明度上限约为 52，招牌文字比牌面更暗，避免道具抢过角色的高光。
- 每帧在前景绘制后叠加一层全画面调色：柔光模式的暖顶冷底渐变加上暖暗色晕影，把视线收回到公路中央；渐变只创建一次，每帧两次填充。
- 丧尸皮肤为饱和青绿、衣物为锈红、芥黄、蓝、紫等高饱和色，血液为深红，与压暗的橄榄灰场景形成冷暖对比。
- 手机竖屏下画布以 cover 方式裁切放大（约 1.03 倍），触屏按键独立于画面下方，生命与弹药面板压在公路上并带深色底衬。

## 动画与战斗表现

- 参考图风格的修长头身比例，双节关节 IK 驱动行走、握枪、瞄准与换弹。
- 换弹时远侧手臂位于躯干后，近侧手臂位于前方；换弹阶段平滑衔接，霰弹枪支撑手与护木同步泵动。
- 八种丧尸体型与非对称步态，配合拖腿、弓背、扑击蓄力、摆头和关节受击动作。服装破损、装备、脸部与手指均使用像素细节绘制。
- 枪托绕肩部瞄准，连射逐渐抬升枪口与扩大散布，停止射击后自动回正。解析弹簧使回弹在不同帧率下保持一致。
- 开火当帧枪身后撞、肩膀受力与枪口上跳，随后按各武器弹簧参数回正；连射累积有上限，停火可恢复准线。后坐力使用真实帧时间恢复，不受命中慢动作拖慢。
- 强化枪口焰、气浪、弹道、抛壳、枪口烟与定向命中粒子，枪声叠加低频冲击和机械声。
- 武器独立击退强度，重装丧尸更抗冲击；霰弹多弹丸击退有上限，同一发命中同一目标不叠播命中声，尸体继承受击冲量。
- 枪口瞬时照明、枪管余烟、命中碎布、持久弹孔与短时弹道残影，配合轻微变化的枪声音色。
- 骨架同步的头部、躯干、上臂、前臂、大腿、小腿独立碰撞检测；高速子弹采用扫掠检测。
- 手枪具有独立单发节奏与后坐回正；撬棍提供消耗体力的近身挥击反馈。丧尸断肢、血肉碎粒与落地残骸延续同一像素美术。
- 尸体与断肢采用 120Hz 固定步长约束物理，带重力、地面碰撞、摩擦和落地扬尘。
- 最多 500 个粒子、15 具尸体、32 个断肢和 240 个地面痕迹，及时回收，避免无限累积。
- 合成分层枪声、命中声、落地声、弹壳声与装弹声，无外部音频依赖。

`npm run check` 检查语法；`npm test` 验证碰撞、断肢、物理约束、效果数量上限、暂停、弹药守恒、武器切换、卷轴瞄准、断肢定身、特殊丧尸及撤离状态。
