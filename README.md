# LAST LIGHT · 死线突围

以荒野公路为背景的原创像素生存射击游戏。无构建依赖，Canvas 2D 实时绘制像素场景和角色。

## 运行

```sh
npm start
```

打开 http://127.0.0.1:5173，也可以直接打开 `index.html`。

## 人物换装实验室

打开 `wardrobe.html`，或通过游戏开始 / 暂停面板中的「人物换装 / 动作测试」进入。实验室和游戏共用 `characters.js` 的骨架、服装分层和武器动画。

- 六个部位：头饰、上衣、裤装、鞋靴、装备、面部配件；四套预设，服装与肤色可独立调整。
- 可测试待机、行走、冲刺、射击、换弹和近战，切换五种武器与朝向，暂停 / 慢放 / 拖动动作时间轴，检查骨架和像素网格。
- 编辑即时预览；点击「保存并应用」后存入本机浏览器，已打开的游戏同步外观，新开游戏也会加载。未保存的试装不会覆盖已保存装扮。
- 近战可单独选择两种下劈招式，调整 ±35° 瞄准角度；时间轴标出蓄力、有效挥击和回收。命中时武器短暂停顿并回弹，世界继续运行。
- 换装只改变外观，不改变碰撞、速度或武器数值。

## 操作

- WASD / 方向键：移动
- 鼠标：瞄准；步枪、冲锋枪与霰弹枪按住左键连续射击；手枪每次点按左键发射一发；撬棍点按或按住左键连续挥击，依次使出斜劈、双手重劈，消耗 16 / 24 体力；停止攻击后重置连段
- 鼠标靠近左右各 18% 的屏幕边缘：平滑拉远镜头（最多增加约 16% 视野），向该侧略微偏移；回到中间恢复。准星和界面保持原尺寸，触屏不触发。
- 1–5：切换 AK-47 步枪、MP5 冲锋枪、M870 霰弹枪、M1911 手枪、撬棍；Q：轮换武器
- M1911 初始弹药为 10 / 90；撬棍以体力驱动，无需弹药
- R：仅为枪械换弹，空弹匣会自动换弹；切换武器取消当前装弹，各枪械独立保存弹药
- Shift：冲刺，消耗体力
- Esc / 空格：暂停或继续
- Enter：开始 / 重新开始
- 触屏：屏幕方向键、换弹和开火按钮；开火时瞄准最近的僵尸

尸群采用少量强敌节奏：首波 10 只（开局先出现 3 只），每组 2–3 只，同时存活上限 14 只，每波最多 20 只；商店 2 只、谷仓 3 只。普通丧尸首波生命 8.5，后续缓慢增加至 12；AK 命中完整躯干需 9 枪、头部需 2 枪（首波），近身攻击造成 25 点伤害。轻型枪械连续命中躯干不再每枪刷新硬直，爆头、霰弹和近战仍能打断攻击。

普通丧尸的基础速度已提升至原来的 2 倍，并强化追击压迫、特殊攻击与受击表现。断肢独立细分为上臂（arm）、前臂（forearm）、大腿（leg）与小腿（shin）；命中对应部位会留下像素血肉断面和断肢。失去一条小腿后跛行，失去任意大腿或双小腿后爬行。腿部损伤与任意臂段缺失同时出现时，丧尸停止自主移动与特殊冲锋；双腿缺失但双臂完整时，仍能依靠手臂爬行。断臂也会削弱攻击。头部伤害依武器和丧尸类型计算，重装丧尸能承受更多命中。每五次击杀掉落弹药或医疗补给，走近即可拾取。每波结束恢复部分生命并补充弹药；后续尸潮逐渐增强。最高击杀记录保存在当前浏览器。

横向卷轴地图长 6400 像素，从暮色农场经过废弃加油站、隔离边界至铁锈工业区。区域边界提供补给，抵达东端后清空残余尸群即可撤离。远山、云层和电线随镜头分层移动，烟、旗帜、草、鸟群和警示灯持续变化；道路采用平行侧视透视，静态背景按块缓存。场景整体压低明度与饱和度，为角色和血肉反馈让出对比。

特殊丧尸包括短暂蓄力后扑击的疾行者、耐伤冲撞的重装暴君、向预判位置抛射腐液并留下危险地面的喷吐者。

所有游戏美术均由代码绘制，无需下载素材。字体加载失败时使用系统字体。开始游戏后启用声音，右上角可关闭。

## 地图与区域

- 公路是一个区域，建筑内部是另一个区域；区域之间由"交界点"连接。目前有三处：第一区谷仓的大门（公路 x≈420）、第二区加油站商店的门（x≈2216）和 17 号住宅（x=4420），位置由 `world.js` 的 `WORLD_PORTALS` 导出。
- 走到门口会出现像素提示"E 进入商店"，按 E（触屏点"进入"）淡出淡入切换到店内；店内左侧出口按 E 回到门口。
- 每个区域各自保存僵尸、尸体、血迹和补给：店里的 2 只僵尸打完就一直是安全的，公路上的尸群在你离开时原地等待。
- 店内有弹药箱和医疗箱各一个，谷仓里有 3 只僵尸和两个补给箱；在室内时公路不刷怪，撤离进度不变。
- 谷仓区包含两种外形：红木山墙谷仓与旧铁皮粮仓。内部有梁架、阁楼阴影、透视地坪、工具墙、粮袋、饲槽和带发动机细节的拖拉机；吊牌、围裙、滑轮绳索、水槽波纹与飞蛾独立运动，门口与吊灯共享场景光照。
- 场景带持续动画：风阵、电线上的乌鸦、风滚草、霓虹灯闪烁、检查站警灯扫射、工厂焊光、谷仓风车与提灯、室内的吊灯摆动、苍蝇、老鼠、滴水等。
- 室内定义在 `interiors.js` 的 `INTERIORS`（长度、出口、补给、刷怪点），公路上的门由 `world.js` 的 `WORLD_PORTALS` 定义；以后岔路、其他建筑都按同一结构添加。

## 17号住宅：门廊灯还亮着

开始菜单点击「探索17号住宅」可直接试玩，也可以在公路 x4420 的前门进入。这是汽车电工诺亚、护士伊芙和女儿露西的家；四条短线索与房间陈设一起讲述停电、防御、救助邻居和撤离的经过。完整设定见 [设计文档](docs/design/miller-house.md)。

- WASD 移动，靠近门、楼梯或纸张按 **E**；**J** 打开已发现线索的手记，Esc / E / J 关闭。触屏使用对应交互按钮和手记按钮。阅读暂停模拟并清除持续开火和移动输入。
- 一楼客厅、餐区、厨房连通；卫生间和洗衣维修间是独立房间。二楼走廊分别进入主卧、儿童房和家庭浴室。儿童房窗口通往门廊屋顶，可沿梯子下到公路 x4710。
- 上下楼有可见的短程行走动画；攀梯时武器收起，手脚交替移动；门框和扶手位于前景。转换期间不能攻击，90 像素内有可移动敌人时不能进门或上楼。
- 住宅仅有厨房和维修间两只固定普通丧尸，二楼没有敌人；餐区一份医疗、维修间少量弹药。门后动静提前提示维修间危险。
- 同一局内保存门窗、线索、尸体、断肢和已消耗补给，回访不会重新生成。重新开始清空住宅探索状态；当前不跨刷新保存本局。
- 八个空间分别缓存像素家具和建筑；窗帘、纸鸟、滴水、浮尘实时运动。门廊与楼梯使用电池暖光，其余房间借窗户照明，枪火沿用统一动态光照。

## 美术风格

- 网页只有一块画布：整个视口就是游戏，画布高 330 像素，宽度随屏幕比例在 640–1280 之间自适应，宽屏无黑边。
- 所有界面都画在游戏画面里（`ui.js`）：生命/体力、波次与撤离进度、击杀与时间、武器挂架、黄铜弹药计数与弹匣刻度、任务面板、声音/暂停/全屏按钮，以及触屏方向键和开火键。
- 数字与英文用代码内置的 5×7 位图字体绘制，中文按整数像素阈值化为一位图并缓存，与场景一起做最近邻放大，保持统一的像素风。

以《They Are Coming!》一类横版尸潮射击为参照：角色厚重易读、打击反馈夸张，冷色丧尸站在暖色世界前。

- 场景是舞台而非主角：农田、芦苇、路肩等中景色带降低约四成饱和度与一成半明度，公路改为偏冷的灰蓝底色，碎石纹理减少到原来的三分之一并压在底色 ±3 明度内，只保留车道线为高饱和暖黄。
- 地平线遵循大气透视：电线、电杆、树带和远处城市轮廓统一向天空色靠拢，不再以深色剪影切割画面。
- 四区建筑具有屋檐和窗沿厚度、墙脚阴影、剥落墙皮、局部露砖、破玻璃后的室内陈设；谷仓、商店、检查站和工厂各自绘制木板五金、货架、设备与管道。远处水塔、城镇、吊车和烟囱采用独立视差。
- 静态建筑按块缓存，风车、提灯、警灯、焊光、旗帜、烟尘、风扇、冷柜与飘动纸张独立实时绘制。建筑跨缓存块时保持纹理连续。
- 暖顶冷底调色统一街景，灯具发光芯在场景中绘制，局部光照由 `lighting.js` 统一处理。灯管具有柔和溢光、地面接光与缓慢的供电变化；人物通过透明轮廓蒙版受光，保留服装和肤色细节。
- 灯光纹理和光照画布复用，按视口剔除远处光源；所有光照仍在逻辑像素画布中合成，再做最近邻放大。
- 丧尸皮肤为饱和青绿、衣物为锈红、芥黄、蓝、紫等高饱和色，血液为深红，与压暗的橄榄灰场景形成冷暖对比。
- 手机竖屏下画布以 cover 方式裁切放大（约 1.03 倍），触屏按键独立于画面下方，生命与弹药面板压在公路上并带深色底衬。

## 动画与战斗表现

- 参考图风格的修长头身比例，双节关节 IK 驱动行走、握枪、瞄准与换弹。
- 换弹时远侧手臂位于躯干后，近侧手臂位于前方；换弹阶段平滑衔接，霰弹枪支撑手与护木同步泵动。
- 八种丧尸体型与非对称步态，配合拖腿、弓背、扑击蓄力、摆头和关节受击动作。服装破损、装备、脸部与手指均使用像素细节绘制。
- 枪托绕肩部瞄准，连射逐渐抬升枪口与扩大散布，停止射击后自动回正。解析弹簧使回弹在不同帧率下保持一致。
- 开火当帧枪身后撞、肩膀受力与枪口上跳，随后按各武器弹簧参数回正；连射累积有上限，停火可恢复准线。后坐力使用真实帧时间恢复，不受命中慢动作拖慢。
- 强化枪口焰、气浪、弹道、抛壳、枪口烟与定向命中粒子，枪声叠加低频冲击和机械声。
- 武器独立击退强度，重装丧尸更抗冲击；霰弹多弹丸击退有上限，同一发命中同一目标不叠播命中声，尸体继承受击冲量。
- 枪口焰由定向外焰、热芯和迅速衰减的尾焰组成，随枪管位置与方向同步。开火时暖光短暂照亮邻近人物和环境；枪管余烟、命中碎布、持久弹孔与短时弹道残影配合变化的枪声音色。
- 骨架同步的头部、躯干、上臂、前臂、大腿、小腿独立碰撞检测；高速子弹采用扫掠检测。
- 手枪具有独立单发节奏与后坐回正；撬棍提供消耗体力的近身挥击反馈。丧尸断肢、血肉碎粒与落地残骸延续同一像素美术。
- 尸体与断肢采用 120Hz 固定步长约束物理，带重力、地面碰撞、摩擦和落地扬尘。
- 最多 500 个粒子、28 具尸体、32 个断肢和 400 个地面痕迹，及时回收，避免无限累积。
- 合成分层枪声、命中声、落地声、弹壳声与装弹声，无外部音频依赖。

`npm run check` 检查语法；`npm test` 验证碰撞、断肢、物理约束、效果数量上限、暂停、弹药守恒、武器切换、卷轴瞄准、断肢定身、特殊丧尸、撤离状态、光源与镜头同步及枪口照明衰减。
